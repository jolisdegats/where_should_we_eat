# 🎡 Where Should We Eat? (React)

⚠️ **WIP Alert:**  
This project is *very much alive* — evolving, tweaking, and fueled by late-night coding sessions (and snacks).

<br/>

## 🍴 The Idea

"Where should we eat?" — the eternal struggle.  
So I built a little something to spin the wheel of fate and make that decision *way* more fun (and way better looking).  
This project is also my playground for SCSS experiments — smooth transitions, cozy neumorphism, shiny glassmorphism — wrapped in a clean React frontend.

There's a live, slightly chaotic version on Netlify if you're feeling adventurous:

👉 [Try the Demo (WIP)](https://where-should-we-eat-jolisdegats.netlify.app/)

## 🛠 Tech Stack

- **Frontend:** React, React Router DOM, SASS
- **Styling Playground:** Neumorphism, glassmorphism, transitions, shadows

<br/>

## 🚀 Upcoming Features

- ✨ Polished restaurant list
- 🎯 Select / Unselect all options
- 🎉 Animated pop-up to reveal the "chosen one"
- 🎨 Wheel customization (colors, icons, spin speeds...)

<br/>

## 💻 Run Locally

Clone the project:  
```git clone https://github.com/jolisdegats/where_should_we_eat.git```

<br/>
Install dependencies:

```npm install```

<br/>
Start the development server:

```npm run dev```
